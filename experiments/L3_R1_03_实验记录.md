# Level 3 / R1 实验记录

## EXP001：ROS2 C++ Talker / Listener

### 1. 实验目标
验证 ROS2 节点发布订阅通信、Topic 类型与消息频率。

### 2. 实验环境
- Windows 10 + WSL2
- Ubuntu 24.04
- ROS2 Jazzy Desktop
- demo_nodes_cpp 官方示例

### 3. 实验输入
- Publisher: demo_nodes_cpp talker
- Subscriber: demo_nodes_cpp listener
- Topic: /chatter
- Message Type: std_msgs/msg/String

### 4. 运行前预测
本次 EXP001 没有保存独立的定量运行前预测。
不能将实验后的解释冒充先验预测。

### 5. 实际结果
- Publisher 正常发布 Hello World 消息。
- Subscriber 收到 Hello World: 6 至 12。
- 最后一次 topic hz 平均频率：1.003 Hz。
- 最短消息间隔：0.972 s。
- 最长消息间隔：1.015 s。
- 消息间隔标准差：0.01329 s。
- 统计窗口：6 个间隔。
- 实验结束后执行了 Publisher 清理命令。

### 6. 结果分析
- Topic 类型为 std_msgs/msg/String。
- Listener 能收到 Publisher 发布的消息。
- 订阅端观测频率接近 1 Hz。
- 消息到达间隔存在正常波动。
- Listener 后启动，没有观察到前面已发布的消息。

### 7. 结论边界
- 本次使用官方 C++ 示例，不是独立编写的节点。
- 已验证基础发布订阅通信。
- 尚未验证自定义 QoS、消息类型错误注入与性能极限。
- 不代表整个 Level 3 或 R1 已通关。

### 8. 下一步
EXP002：1 Hz 与 5 Hz 发布频率对照实验。

## EXP-R1-CPP-PUB-001：自主 C++ Publisher

### 实验目标
验证独立编写的 ROS2 C++ Publisher 能否正常运行，
并验证事先预测的 200 ms / 5 Hz 发布行为。

### 实验环境
- ROS2 Jazzy
- Ubuntu 24.04 / WSL2
- Package: l3_r1_cpp
- Executable: l3_talker

### 运行前预测
- Node: /l3_talker
- Topic: /l3/chatter
- Message: std_msgs/msg/String
- Content: RGBD ready
- Period: 200 ms
- Expected receive rate: approximately 5 Hz

### 实际结果
- colcon build: PASS
- ros2 pkg executables: l3_r1_cpp l3_talker
- ros2 node list: /l3_talker, /talker
- ros2 topic type: std_msgs/msg/String
- ros2 topic echo --once: RGBD ready
- Last measured average rate: 4.996 Hz
- Minimum received interval: 0.184 s
- Maximum received interval: 0.217 s
- Interval standard deviation: 0.00913 s
- Measurement window: 88 intervals

### 结果分析
- Publisher 可执行文件已完成编译、链接和安装。
- ROS2 成功发现并运行自定义节点。
- 订阅端收到了预期类型和内容的消息。
- 实测接收频率与 5 Hz 预测一致。
- 接收端统计不能直接证明内部 Timer 的精确调度周期。
- /talker 额外节点的来源尚未核验。

### 验收边界
- 自主 C++ Publisher 运行时验证 PASS。
- 自主 C++ Subscriber 尚未实现。
- 尚未执行自动化测试和 QoS 故障注入。
- Git Commit / GitHub Push 尚未完成。
