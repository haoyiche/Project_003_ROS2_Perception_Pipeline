# T01 v2：ROS2 自动化通信测试与失败分类

## 目标
验证自动测试能够区分：
1. 正常通信
2. 预期 Topic 不匹配
3. 节点意外提前退出

## 实验环境
- WSL2 Ubuntu 24.04
- ROS2 Jazzy
- ROS_DOMAIN_ID=67
- Package: l3_r1_cpp
- Test: tests/test_r1_pubsub_basic_v2.sh

## 运行前预测
- normal: 返回 0，收到 RGBD ready
- wrong-topic: 返回 0，Graph 显示故意分离的端点，节点持续存活
- 意外退出: 返回 3，不得误判为预期无消息

## 实测
### normal
GRAPH_ASSERTION_PASS: /l3/chatter
PASS_NORMAL
测试脚本返回 0

### wrong-topic
GRAPH_ASSERTION_PASS: /l3/chatter_wrong
PASS_EXPECTED_NO_MESSAGE
测试脚本返回 0

### Listener 提前退出
注入 SIGTERM 至 Listener PID 32418
FAIL_NODE_EXIT: listener stopped unexpectedly
HARNESS_EXIT_CODE=3
T01_V2_UNEXPECTED_EXIT_CLASSIFICATION_PASS

## 分析
- 被测节点退出码与测试脚本退出码必须区分
- 预期无消息不要求 Listener 输出错误日志
- ROS Graph 是故障归因的重要证据
- 正常通信和预期故障均可令测试脚本返回 0
- 节点提前退出必须独立归类

## 结论边界
- SIGTERM 验证的是提前退出检测，不等同于真实 segfault
- ROS Graph 清理检查通过，但尚未独立审计全部操作系统进程
- T01 v2 是一个测试脚本，覆盖三个场景，不等于三条独立测试
