# T01：C++ Publisher / Subscriber 自动化测试

## 目标
构建能够自动启动、判断、清理和记录 ROS2 通信测试的 Bash 脚本。

## 测试脚本
tests/test_r1_pubsub_basic.sh

## 运行前预测
- normal：收到 5 条匹配消息，返回 0
- wrong-topic：订阅错误 Topic，超时并返回非零
- 测试结束后清理本次启动的节点

- 当前负向验收只判断退出码非零
- 其他运行错误也可能被误判为预期故障
- ROS Graph 为空不等于独立验证了全部 OS 进程
- 这是一条自动化测试脚本，包含两个测试场景
